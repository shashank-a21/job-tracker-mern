# Job Tracker (MERN Stack)

A full-stack web application to manage and track job applications efficiently.
Built using the MERN stack with authentication and analytics features.

---

## 🚀 Tech Stack

* Frontend: React.js, Tailwind CSS
* Backend: Node.js, Express.js
* Database: MongoDB
* Authentication: JWT (planned)

---

## ✨ Features

* User authentication (in progress)
* Add, edit, delete job applications
* Track job status (Applied, Interview, Offer, Rejected)
* Dashboard with analytics (planned)
